## Summary

On 2026-10-10 opencode replaced `dev` with its v2 line: `packages/opencode` is gone, and the code now lives in `core`, `ai` (its own multi-protocol LLM SDK in place of Vercel's AI SDK), `tui`, `cli`, `server` and a typed `plugin` API. Most of v2 is a client/server rebuild, plugins and remote pairing, all non-goals for nth. What carries over is model-facing polish (forgiving edits, tool-argument repair, grep/glob options, Anthropic thinking replay, refusals) and worktree and CLI tools that fit nth's goals. Front-runners: the worktree setup command and tools, tool-argument repair, thinking replay, `nth run --session` with JSON output, and the Diff tab.

The v2 items were triaged by area (core, TUI, providers, CLI and plugins) from the branch's `feat` commits; the first-parent commits after the merge are mostly fixes.
