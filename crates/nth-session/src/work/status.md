Show the work plan: each cycle, whether it is closed, current or waiting, and each item with where it stands, who works on it and how far its todo is. Below the cycles it lists the subagents this plan started in this run of nth: each one's task id, whether it is running, idle or ended, and the items it worked on. An idle one can take another item with work_assign's `task_id`.

Use it when you resume a session or before you plan the next cycle. It is not for waiting: changes to items reach you as notices on their own.
