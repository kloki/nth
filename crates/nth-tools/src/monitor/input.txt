Writes text to the stdin of a running monitor started with `stdin: true`, by the id the monitor tool gave, as a user typing into a terminal would. The text goes in as it is: end each line with `\n`, as pressing Enter would. What the command prints in answer reaches you as notices, like the rest of its output. Set `close` to close stdin after the text, or alone with no text, when the command reads until end-of-input. The call waits up to 5 seconds for the command to take the text; if it has not by then, the result says so and the text goes in when the command reads.

Write to one monitor one call at a time, never in parallel calls in the same reply: the order parallel calls arrive in is not yours to choose. When you want text and then end-of-input, send both in one call, the text with `close` set.
