# Plan: `fwrkt` + `cleanwrkt` — fzf jump to worktrees and bulk cleanup

## Goal

Add two shell functions to `~/.bashrc`:

- `fwrkt` — list the worktrees of the repo you are in, pick one with fzf, `cd`
  into it.
- `cleanwrkt` — remove every worktree of the repo except the main one, in one
  go, skipping (and warning about) any with uncommitted or untracked changes.

- Your worktrees live as **siblings** under `~/repos/` (e.g. repo `nth`, plus

### Jump

```bash
# cd into one of the current repo's git worktrees, picked with fzf
fwrkt() {
    git rev-parse --git-dir >/dev/null 2>&1 || {
        echo "fwrkt: not in a git repository" >&2
        return 1
    }
    local cur sel
    cur=$(git rev-parse --show-toplevel 2>/dev/null || git rev-parse --git-dir)
    sel=$(
        git worktree list --porcelain | awk -v cur="$cur" '
            /^worktree / { wt = substr($0, 10); next }
            /^branch /   { b = substr($0, 8); sub(/^refs\/heads\//, "", b);
                           printf "%s%s\t%s\n", (wt == cur ? "* " : "  "), b, wt; next }
            /^detached/  { printf "%s(detached)\t%s\n", (wt == cur ? "* " : "  "), wt }
        ' |
            fzf --delimiter '\t' --with-nth=1,2
    ) || return
    cd "${sel#*$'\t'}" || return
}
```

### Bulk cleanup

```bash
# remove every worktree of the current repo except the main one; skip dirty ones
cleanwrkt() {
    git rev-parse --git-dir >/dev/null 2>&1 || {
        echo "cleanwrkt: not in a git repository" >&2
        return 1
    }
    local main cur removed=0 skipped=0 line path
    main=$(git worktree list --porcelain | awk '/^worktree /{ print substr($0, 10); exit }')
    cur=$(git rev-parse --show-toplevel 2>/dev/null || git rev-parse --git-dir)

    while IFS= read -r line; do
        path=${line#*$'\t'}
        [ "$path" = "$main" ] && continue
        if [ "$path" = "$cur" ]; then
            echo "cleanwrkt: skipping current worktree $path" >&2
            skipped=$((skipped + 1))
            continue
        fi
        if [ -n "$(git -C "$path" status --porcelain 2>/dev/null)" ]; then
            echo "cleanwrkt: dirty, skipping $path" >&2
            skipped=$((skipped + 1))
            continue
        fi
        if git worktree remove "$path"; then
            echo "cleanwrkt: removed $path"
            removed=$((removed + 1))
        else
            echo "cleanwrkt: failed to remove $path" >&2
            skipped=$((skipped + 1))
        fi
    done < <(git worktree list --porcelain | awk '
        /^worktree / { wt = substr($0, 10); next }
        /^branch /   { b = substr($0, 8); sub(/^refs\/heads\//, "", b); printf "%s\t%s\n", b, wt; next }
        /^detached/  { printf "(detached)\t%s\n", wt }
    ')

    git worktree prune
    echo "cleanwrkt: removed $removed, skipped $skipped"
}
```

### Notes on the implementation

- `git worktree list --porcelain` is parsed with awk. `fwrkt` prints
  `branch<TAB>path` and `*`-marks the worktree you are currently in; fzf shows
  both fields (`--with-nth=1,2`) and returns the whole line, so cd uses the path
  after the tab (`${sel#*$'\t'}`).
- `cleanwrkt` treats the first porcelain entry (`git worktree list` always lists
  the main worktree first) as the one to keep, and also skips the worktree you
  are currently in — removing the ground under the shell would break `$PWD`.
- Dirty = `git worktree status --porcelain` is non-empty (staged, modified or
  untracked). Those are skipped with a warning and left intact; there is no
  `--force`. Clean ones are removed with the plain `git worktree remove`.
- `git worktree prune` runs at the end to drop bookkeeping for any dirs that were
  already gone.
- **Branches are not deleted** — only the worktree directories are removed. The
  feature branches (`nth/mode`, `nth/plan-edit`, …) remain. Say the word if you
  want branch deletion folded in.
- Esc / no match in `fwrkt`: fzf returns non-zero, the `|| return` leaves you
  where you are. Outside a repo both functions print an error and return 1.
- Both must stay shell **functions** (not scripts) so `cd` and the safety skip
  affect the current shell — which is why they go inline in `~/.bashrc`.
